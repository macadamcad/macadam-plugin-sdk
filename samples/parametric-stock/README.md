# Parametric Stock

Install this folder, then choose **Add Oversize Stock**. Defaults produce a **104 × 64 × 22 mm** box. Edit Finished width, Finished depth, Finished thickness and Allowance per side in the normal inspector.

This package requests `feature:solid` and `kernel:build`. It registers a declarative box template; it does not execute a JavaScript geometry callback. Source, manifest and icon are copied unchanged from Macadam's shipping examples.

Save/reopen and undo/redo use the ordinary document feature path. Keep the required package version installed on each evaluating machine. Uninstalling retains the feature's authored intent; reinstalling restores availability.
